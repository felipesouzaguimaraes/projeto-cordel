Este projeto consiste na criação de um site focado na belíssima poesia "Cordel Moderno", escrita por **Milton Duarte**. O projeto foi desenvolvido como o **Desafio 12 (Módulo 3)** do curso de HTML5 e CSS3 do **Curso em Vídeo**, sob orientação do professor **Gustavo Guanabara**.

O grande objetivo deste desafio foi aprender a trabalhar com imagens de fundo fixas e aplicar o famoso **efeito de rolagem Parallax**, onde o texto passa por cima das imagens criando uma sensação de profundidade moderna e dinâmica no navegador.

## 🎨 Conceitos Visuais e Funcionalidades

O site foi estruturado para simular a leitura de um folheto de cordel misturado com a modernidade da web:

| Aspecto Técnico | Implementação Aplicada |
| :--- | :--- |
| **Efeito Parallax** | Uso da propriedade `background-attachment: fixed` combinada com configurações de tamanho e posicionamento de imagem para fixar os fundos enquanto o texto rola. |
| **Tags de Texto** | Aplicação correta de tags semânticas para poemas, estruturando cada estrofe dentro de blocos específicos e quebras de linha controladas (`<br>`). |
| **Estilização Temática** | Fundo escuro contrastando com caixas brancas de texto texturizado, remetendo ao papel dos folhetos de cordel tradicionais. |
| **Tipografia Personalizada** | Escolha de fontes adequadas para dar um ar artístico e poético à leitura do texto no ambiente digital. |

## 📂 Estrutura de Arquivos do Repositório

O projeto possui uma organização de arquivos simples e direta:

* `index.html` — Estrutura e marcação com o texto completo da poesia de Milton Duarte.
* `estilos/` (ou pasta de estilo correspondente)
  * `style.css` — Arquivo contendo toda a lógica de posicionamento, centralização do texto e os seletores das imagens fixas em Parallax.
* `imagens/` — Contém as ilustrações de fundo utilizadas nas transições do cordel.

---

## 🚀 Como Executar o Projeto Localmente

Por ser um projeto puramente Front-End estático, você pode rodá-lo instantaneamente:

1. Baixe os arquivos ou clone este repositório.
2. Abra a pasta principal do projeto.
3. Dê um duplo clique no arquivo `index.html` para executá-lo em seu navegador padrão e role a página para testar os efeitos visuais.
